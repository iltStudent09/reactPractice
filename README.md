# React Practice Starter

A starter React + Vite project for practicing React concepts.

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` - start development server
- `npm run build` - build for production
- `npm run lint` - run ESLint
- `npm run preview` - preview production build

## Add practice items

- Create practice components under `src/practice`
- Render them from `src/App.jsx`
- Use `CounterPractice` as a starter pattern for new components
